# Early-access UAT checklist

Record tester, date, branch/SHA or build identifier, browser/device, scenario result, severity, screenshot/log references, and sign-off for every run. Do not mark a scenario signed off without a real tester result.

## Scenarios

- [ ] Registration, login, logout, email verification, password reset
- [ ] Create, switch, and isolate multiple wedding workspaces
- [ ] Invitations, owner/editor/viewer roles, ownership transfer
- [ ] Tasks, timeline, and events
- [ ] Budget, ten flexible payment terms, calculations, savings
- [ ] Seserahan and administration checklists
- [ ] Private vendor contacts
- [ ] Guests, rundown/print, and playlist
- [ ] Custom fields and private attachments
- [ ] Authorized exports and viewer export denial
- [ ] Cross-wedding isolation and private file denial
- [ ] Desktop, mobile, keyboard, and accessible states
- [ ] Backup/restore/reconciliation and recovery drill

Release-blocking severity includes data leakage, unauthorized mutation/download/export, financial corruption, failed restore, broken registration, or an unusable primary mobile flow.
